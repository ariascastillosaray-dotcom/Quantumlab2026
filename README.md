# QuantumLab2026

QuantumLab2026 is a personal computational physics project developed in Python.
The repository contains numerical experiments and simulations related to physics.
It is organized into different folders according to the topics studied.

## Structure

`docs/` — Documentation and additional project notes.
`figures/` — Generated plots and figures (from projects).
`projects/` — Main folder wich includes:

- `quantum/` — Quantum mechanics simulations and wave/particle models.
- `pendulum/` — Pendulum simulations and energy conservation analysis.
- `harmonic_oscillator/` — Harmonic oscillator and numerical energy analysis.
- `projectile_motion/` — Projectile motion simulations and error analysis.
- `numerical_methods/` — Numerical methods and ODE experiments.
- `legacy/` — Previous training sessions and early experiments.
